# Get started

Each page here takes you from nothing to a first working call with one client. Pick the one you use:

- [Claude Desktop](claude-desktop.md): the app starts the server on your machine.
- [Claude Code](claude-code.md): the plugin, or a command Claude Code starts for you. The same page connects it to a server that already runs.
- [A remote server](http-client.md): someone gave you a URL, and you want claude.ai or another client to use it.
- [Installation](installation.md): every way to install the server, and how to check what you installed.

A first setup is the moment to decide what the server may touch. What it can reach, what it changes and who gets in is set out in the [security model](../security-model.md); each tutorial says which of that its setup allows.

Point the server at a folder of Markdown notes, an Obsidian vault included, and start read-only: Claude can search and read your notes but not change them. Writing, git commits and search by meaning come after, from [Use](../use/index.md).
