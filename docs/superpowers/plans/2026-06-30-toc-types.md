# Type the TOC payloads as dataclasses — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the TOC methods' raw `dict[str, Any]` payloads with `@dataclass` types (`TocEntry`/`SubtreeNote`/`SubtreeToc`), `asdict()`-ed at the MCP boundary, so mypy type-checks the shapes while the JSON wire format stays byte-identical (#779).

**Architecture:** Add three dataclasses to `types.py` and a `utils/serialization.py:toc_payload` helper (additive, Task 1). Then thread the types through the FTS → manager → facet layers and convert to dicts at the tool + resource boundaries, updating library-level test assertions in lockstep — one atomic change because the union return type flows end-to-end and any partial application leaves the suite red (Task 2). Docs + verification (Task 3).

**Tech Stack:** Python 3.11+, `@dataclass` / `dataclasses.asdict`, SQLite FTS5, FastMCP, pytest, `uv`, `ruff`, `mypy`.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-06-30-toc-types-design.md` (authoritative).
- **JSON wire shape is unchanged.** `asdict` recurses nested dataclasses, so the tool's `structured_content`, the resource's `json.dumps` body, and the tool's advertised output schema stay byte-identical. MCP-level tests (`test_server.py`) MUST NOT change — they are the wire-shape regression guard.
- The tool's return annotation stays `list[dict[str, Any]] | dict[str, Any]` (a union) → `force_result_wrap=True` stays.
- No behavior/bounds/API change to the TOC feature: dispatch on `.md`, the two shapes, `max_notes`/`max_level` semantics, the `max_* < 1` guards, boundary match, and the "FTS returns raw headings; manager prepends the synthetic H1" contract are all preserved.
- Dataclasses match the existing `types.py` style (plain `@dataclass`, no `slots`/`frozen` unless neighbors use them).
- `asdict` is already imported in `_server_tools/reader.py` and `_server_resources.py`.
- Gates before each commit that touches `src/`: `uv run ruff check --fix .` then `uv run ruff format .` then `uv run ruff format --check .`, `uv run mypy src/ tests/`, `uv run pytest -x -q`. Conventional commits.

Create `src/markdown_vault_mcp/utils/serialization.py`:

```python
"""Serialization helpers for converting library result types to JSON-able dicts."""

from __future__ import annotations

from dataclasses import asdict
from typing import Any

from markdown_vault_mcp.types import SubtreeToc, TocEntry


def toc_payload(
    data: list[TocEntry] | SubtreeToc,
) -> list[dict[str, Any]] | dict[str, Any]:
    """Convert a ``get_toc`` result to its JSON-able dict form.

    Note mode returns a ``list[TocEntry]`` → a list of dicts; folder mode
    returns a ``SubtreeToc`` → a nested dict (``asdict`` recurses the
    ``SubtreeNote`` / ``TocEntry`` children).
    """
    if isinstance(data, SubtreeToc):
        return asdict(data)
    return [asdict(entry) for entry in data]
```
