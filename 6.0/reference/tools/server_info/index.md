# Server info

## `get_server_info`

**Server Info.** Read-only.

Report the version information of markdown-vault-mcp; returns `server_name`, `server_version`, `core_version`, the MCP protocol revisions supported and the revision and client of this connection, and, when configured, the upstream service's version. Use it when asked which version or build is running or which protocol revision is in use.

**Parameters**

None.

**Returns**

`object`
