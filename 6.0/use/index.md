# Use markdown-vault-mcp

This section is for readers who already run the server and want more out of it: how to use its features for real tasks, and why they behave as they do. Each page covers one task or one feature.

For what the server can reach and change while you use it, see the [security model](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/security-model/index.md).

The first pages cover this server's own features: [search by meaning](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/embeddings/index.md), [choosing where its vectors live](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/embedding-stores/index.md) and [keeping them in PostgreSQL](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/postgresql/index.md), [git](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/git-integration/index.md), the [vault explorer](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/vault-explorer/index.md) and [Open Knowledge Format](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/okf/index.md). The rest are ways to run a vault with it: [Obsidian on every device](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/obsidian-everywhere/index.md), [PARA](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/para/index.md), a [Zettelkasten](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/zettelkasten/index.md) and [research](https://pvliesdonk.github.io/markdown-vault-mcp/6.0/use/research-workflows/index.md). The PARA and Zettelkasten pages use example prompts and templates from the repository, and each says how to install them.
