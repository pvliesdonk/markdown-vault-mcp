# Provenance of the bundled OKF specification

`SPEC.md` is the Open Knowledge Format (OKF) specification, Version 0.3, the
one version this server reads and writes.

- Source: `SPEC.md` in
  [open-knowledge-format/open-knowledge-format](https://github.com/open-knowledge-format/open-knowledge-format)
  at commit `527e81aff55992be21507e97004286789126f88c` (18 November 2026):
  <https://github.com/open-knowledge-format/open-knowledge-format/blob/527e81aff55992be21507e97004286789126f88c/SPEC.md>
- License: Apache License, Version 2.0. `LICENSE.md` is that repository's
  `LICENSE.md` at the same commit. The repository has no `NOTICE` file.
- Changes: none to `SPEC.md`, which is byte for byte the file at that commit.
  `LICENSE.md` lacks the blank line that ended the upstream file.

`SPEC.md` and `LICENSE.md` stay under Apache-2.0. `SKILL.md`, this file and
